## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的副本要跨机架分布，避免整个机架故障时数据全丢，同时还要考虑均衡。请从零实现一个机架感知的副本放置组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持登记节点及其机架归属，支持机架内的可用域（例如同一机架的不同交换机）；2) 支持按副本数生成放置方案：优先把副本分散到不同机架，机架不足时再分布到不同可用域；3) 支持机架故障模拟：随机让一个机架失效，剩余副本必须仍然满足最小可用数，需有测试证明；4) 支持数据均衡：各节点承载的数据量差异不超过配置比例；5) 支持节点增删后的重新放置：新增节点时只迁移必要的数据，并给出迁移量统计；6) 支持放置约束冲突的明确报错（例如副本数超过可用机架与域的组合上限）；7) 提供统计：机架分布、可用域分布、均衡偏差与迁移数据量；8) 测试覆盖跨机架分散、机架故障存活、均衡约束、节点增删重放、约束冲突与统计；`mvn -q verify` 一条命令跑通。
